# AI Screen Snapping

An Electron + TypeScript + React desktop tool that lets you select any region of your screen and ask an AI about it, without leaving what you are doing.

## Setup

```bash
npm install
```

## Commands

```bash
npm run dev     # starts Vite + Electron in dev mode
npm run build   # production build
```

## Environment

Create a gitignored `.env` file in the repo root holding `ASU_API_KEY`. It is required to call the ASU API.
